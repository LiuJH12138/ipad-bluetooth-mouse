# 用 AI 操作 iPhone 或 iPad

适用于 iPad Control Console 1.6.0。USB 把画面送到 Windows，蓝牙把键鼠输入送回设备。先明确用户指定的设备和任务终点，例如「在 iPhone SE 搜索 7319，读回后清空」。只要求查看时，读图即可。

## 选择入口

| 当前会话实际具备的能力 | 使用方式 |
| --- | --- |
| 能看到并点击这台 Windows 电脑上的控制台窗口 | 用下面的「画面操控」。脚本授权可保持关闭。 |
| 无法操作窗口，但能在这台 Windows 电脑上运行命令，并能查看生成的 JPEG | 使用随安装包提供的 `assistant.js`。请读[本机命令模式](references/local-commands.md)。 |
| 只有聊天、浏览器标签页或远程执行环境，且无法访问本机控制台或其画面 | 说明缺少哪项能力，提供手动步骤；只把实际观察到的结果报为已完成。 |

用户指定了入口就沿用。只有浏览器自动化时，先确认它确实能访问正在投屏的控制台。仅能运行命令但无法读取图像时可以检查连接状态，按画面选目标的操作需等到能看到画面。

## 开始前核对目标

在控制台确认当前投屏的**设备名与八位短码**。多台连接时用「切换设备」选择目标。蓝牙列表里的电脑名称可能相同。首次连接可点「一键配置」，按提示解锁、配对并开启辅助触控。需要键鼠时，等控制台从所选设备的回传画面核对指针；若提示重新验证，可停在清晰的静止页面再试。命令模式下由用户在该窗口完成选择和授权。

## 有 Computer Use 时，在窗口里操作

1. 选中控制台窗口，看到当前投屏后，从「操控方式」选 **画面操控**。「键鼠控制」会捕获实体鼠标，通常留给手动使用。
2. 从当前窗口截图定位目标。投屏内容是画布，设备上的按钮可能没有对应的 Windows 可访问性节点。点击画布中的输入框，看到光标、键盘或其他焦点变化后，再向当前窗口输入。窗口缩放、旋转或切换全屏后，重新看图定位。
3. 从设备回传的新画面核对结果。例如输入搜索词后读回搜索框，要求清空时再确认占位文字恢复。命令回执或鼠标动画本身不能证明设备完成了操作。完成后，从「操控方式」切回 **仅预览**。

## 画面或连接发生变化时

窗口提示等待新画面、设备切换或蓝牙重连时，停下当前输入。恢复后重新核对目标、观察上一步是否已生效，再决定是否继续。尤其是发送或确认按钮，结果不清楚时不要重复点。切换设备会撤销上一台的脚本授权。
